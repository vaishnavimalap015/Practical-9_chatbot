## Key Features

1. **Prompt Engineering Lab:**
   - **Zero-Shot:** Direct inference without exemplars.
   - **Few-Shot:** Contextual pattern matching with structural demonstrations.
   - **Role Prompting:** Persona conditioning as an Executive Principal AI Systems Architect.
   - **Chain-of-Thought (CoT):** Multi-step cognitive reasoning protocol to reduce hallucination.

2. **Core NLP Specialists:**
   - **Question Answering (QA):** Returns 3 architectural pillars, a live vector Mermaid.js flowchart, and a multi-dimensional impact matrix.
   - **Text Summarization:** Executive TL;DR callout, word reduction analytics bar chart, and domain impact breakdown table.
   - **Aspect-Based Sentiment Analysis (ABSA):** Continuous confidence distribution donut chart and phrase-level hardware/software aspect breakdown table.

3. **Response Quality Score (RQS):**
   - Arithmetic mean formula: $\text{RQS} = \frac{\text{Accuracy} + \text{Relevance} + \text{Consistency} + \text{Fluency}}{4}$
   - Real-time telemetry dock with interactive calibration sliders.

4. **Mobile Responsive Architecture:**
   - Touch-panned tables (`overflow-x-auto touch-pan-x`) and charts.
   - Slide-over navigation drawer with backdrop overlay.
   - Floating command bar tuned for mobile viewports.
